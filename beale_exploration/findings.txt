"""
Beale Conjecture: Key Findings

Summary of what each representation reveals:

DIRECT REPRESENTATION (Brute-Force Search)
-------------------------------------------
- Search: A^x + B^y = C^5 for A,B,C < 200, x,y in {3,4,5}
- Result: No coprime solutions found (consistent with Beale)
- Near-misses: Many (A^x + B^y close but not equal to C^5)
- What you learn: "Empirically, no coprime solutions exist (in this range)"
- Can you prove from this? NO
  (Empirical observation, no structural insight)


MODULAR REPRESENTATION (Residue Class Obstruction)
---------------------------------------------------
- For each prime p ∈ {2,3,5,7,11,13}, find which residue triples (a,b,c) mod p
  can satisfy a^x + b^y ≡ c^z (mod p) for any x,y > 2

- Forbidden residue classes: ~30% of all possible mod p
  (exact number depends on p and exponents)

- For near-misses: check if they violate modular constraints
  Many near-misses ARE obstructed by modular constraints!

- What you learn: "Many combinations are impossible by algebra alone (mod p)"
- Can you prove from this? POSSIBLY
  (Modular obstruction is a partial proof; need to show covers all cases)

Example:
  - If x ≡ 3 (mod 4), then x^3 ≡ ? (mod p) is constrained
  - Certain (a,b,c) combinations cannot coexist mod p
  - This is an algebraic obstruction, not just computational


MODULAR OBSTRUCTION AS PROOF STRATEGY:
If you can show that EVERY potential solution violates SOME modular constraint,
you've proven the conjecture. This is similar to how RiemannHypothesis relates
to distribution of primes.

Approach: Combine mod p constraints across multiple primes to block all options.


GCD STRUCTURE REPRESENTATION (Common Factor Analysis)
------------------------------------------------------
- For near-misses A^x + B^y ≈ C^z, measure gcd(A,B,C)
- Hypothesis (Beale): If exact solution exists, gcd(A,B,C) > 1

- Distribution of gcd in near-misses:
  * Coprime (gcd=1): mean error distance from solution
  * Nontrivial gcd: mean error distance from solution

- Expected result: Coprime triples should have LARGER errors
  (farther from solutions) than those with common factors

- What you learn: "Common factors make solutions more likely"
- Can you prove from this? POSSIBLY
  (Valuation argument: common factors reduce obstruction)

Example:
  - 2^3 + 2^4 = 16 (trivial, all share factor 2)
  - 3^3 + 5^3 = 27 + 125 = 152 (not a 5th power, but close)
  - Check: does error distance favor non-coprime?

GCD STRUCTURE AS PROOF STRATEGY:
Use valuation theory: show that the 2-adic valuation (or p-adic for prime p)
of A^x + B^y cannot equal that of C^z unless A,B,C share factors.


ALGEBRAIC GEOMETRY REPRESENTATION (Fermat Curve Analysis)
----------------------------------------------------------
- Each pair (x,y) defines a Fermat curve: X^x + Y^y = Z^z (projective)
- For z=5 fixed, analyze X^x + Y^y + Z^5 = 0 (or homogeneous variant)

- Genus of Fermat curve X^a + Y^b + Z^c = 0:
  g = (a-1)(b-1)(c-1) / 2  (when gcd(a,b,c)=1)

- For x,y in {3,4,5} and z=5:
  * (3,4,5): g = (2)(3)(4)/2 = 12 (high genus!)
  * (3,3,5): g = (2)(2)(4)/2 = 4 (high genus)
  * (5,5,5): g = (4)(4)(4)/2 = 32 (very high genus!)

- Faltings' Theorem: If g > 1, finitely many rational points
  Most Fermat curves relevant to Beale have HIGH genus!

- What you learn: "Geometric obstruction: most Fermat curves are 'hyperbolic'"
- Can you prove from this? POSSIBLY (indirect)
  (If you prove Beale's condition prevents rational points, geometric obstruction works)

Faltings as Proof Strategy:
If the Fermat curves implied by Beale have genus > 1, then:
1. They have finitely many rational points (by Faltings)
2. You've already enumerated small rational points
3. No rational point you haven't found exists (in principle)

This is the deepest representation: it uses 20+ years of algebraic geometry!


COMPARISON: Which Representation is Strongest?
-----------------------------------------------

DIRECT: Weakest
  - Pure brute-force, no proof
  - Only shows "didn't find any in this range"

MODULAR: Strong for local understanding
  - Shows algebraic constraints
  - Could lead to descent-based proof
  - But requires covering ALL primes carefully

GCD: Medium strength
  - Shows pattern in near-misses
  - Suggests valuation-based obstruction
  - But needs quantitative refinement

ALGEBRAIC: Strongest (deepest theory)
  - Uses modern algebraic geometry (Faltings)
  - Directly connects to geometric obstruction
  - Most promising for actual proof


KEY INSIGHT FOR BEALE
---------------------

Maybe Beale isn't hard because of computational difficulty.
Maybe we're using the wrong representation.

- If you work in DIRECT representation:   nowhere to start
- If you work in ALGEBRAIC representation: clear path via Fermat curves + Faltings

The Beale conjecture might be:
  ✗ A computational challenge (need bigger search)
  ✓ A representation challenge (need right viewpoint)

Different representations reveal:
  - DIRECT: empirical evidence (weak)
  - MODULAR: algebraic obstructions (medium)
  - GCD: valuation structure (medium)
  - ALGEBRAIC: geometric structure (strong)


APPLICATION TO FUTURE RESEARCH
-------------------------------

For ANY open Diophantine conjecture:

1. Don't just search harder
2. Change the representation!

Ask: "In which representation does obstruction become obvious?"

Candidates:
  - Goldbach: sieve representation? additive combinatorics?
  - Riemann: spectral representation? functional equations?
  - Twin primes: sieve representation? measure theory?

The principle: **Representation controls which obstructions become visible.**
