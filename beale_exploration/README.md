# Beale Conjecture: Representation-Dependent Structure

A proof-of-concept exploration of how **representation changes search visibility** in the Beale conjecture.

## The Beale Conjecture

$$A^x + B^y = C^z, \quad x, y, z > 2, \quad A, B, C > 0$$

**Beale's Claim:** If a solution exists in positive integers with $x, y, z > 2$, then $\gcd(A,B,C) > 1$.

(Equivalently: if $\gcd(A,B,C) = 1$, then no solution exists.)

## Hypothesis

The same Diophantine equation, expressed in different representations, reveals different structural patterns about whether common factors *must* exist.

> **Does representation govern which algebraic obstructions become visible in Beale?**

## Four Representations

### 1. **Direct Search Representation**
- **What you do:** Iterate $(A,B,C,x,y)$ over bounded range; check if $A^x + B^y = C^z$
- **What's visible:** Empirical solutions (or lack thereof)
- **Structure revealed:** None (brute-force enumeration)
- **Algorithmic approach:** Exhaustive search with pruning

### 2. **Modular Obstruction Representation**
- **What you do:** For each prime $p$, analyze which residue classes $(a,b,c)$ can satisfy $a^x + b^y \equiv c^z \pmod{p}$
- **What's visible:** Algebraic obstructions modulo primes
- **Structure revealed:** Which combinations are impossible (Weil bounds, Fermat)
- **Algorithmic approach:** Eliminate candidates via modular constraints (like SAT/SMT)

### 3. **GCD Structure Representation**
- **What you do:** For coprime triples $(A,B,C)$ with $\gcd=1$, measure "how close" to finding a solution
- **What's visible:** Which prime powers divide $A^x + B^y - C^z$ (valuation structure)
- **Structure revealed:** Algebraic divisibility constraints
- **Algorithmic approach:** Factor-based analysis

### 4. **Algebraic Geometry Representation**
- **What you do:** View $A^x + B^y = C^z$ as points on Fermat curves; use Mordell-Weil/descent theory
- **What's visible:** Rational point structure via algebraic geometry
- **Structure revealed:** Geometric obstruction to rational solutions
- **Algorithmic approach:** Descent-based proof strategies

## Scope

To make computation tractable:
- Fix $z = 5$ (search $A^x + B^y = C^5$)
- Vary $x, y \in \{3, 4, 5\}$
- Search $A, B, C \in [2, 200]$ 
- Check for coprime triples and Beale structure

## Key Files

- `beale_representations.py` — Main experiment; runs all four representations
- `interpret_results.py` — Visualization and interpretation script
- `beale_results.json` — Output data (generated by first script)

## Quick Start

```bash
# Run the analysis (searches A^x + B^y = C^5 in bounded range)
python beale_representations.py

# Interpret results and see what each representation reveals
python interpret_results.py beale_results.json
```

## Expected Output

A detailed breakdown of:
- **Direct:** How many solutions exist (should be: none with gcd=1)
- **Modular:** Which modular classes are forbidden by small primes
- **GCD:** Divisibility pattern of near-misses
- **Algebraic:** Rational point obstructions

## Connection to Main Paper

This exploration tests whether the principle from `paper_draft.md`:

> **"Representation governs search reachability under bounded budgets"**

applies to Diophantine equations. In Beale:

- Each representation acts as a *different search space*
- Some reveal obstructions (modular, algebraic) better than others (direct)
- A proof strategy that works in one representation may fail in another

## Limitations

- **No new solutions** (obviously — Beale is a $1M open problem)
- **Fixed $z=5$** (generalization to all $z$ is heavier)
- **Coprime search only** (the interesting case per Beale's claim)
- **Small bounds** ($A,B,C < 200$ for tractability)
- **Exploratory only** — demonstrates the principle, doesn't advance Beale

## What This Demonstrates

✓ Same equation, four different representations  
✓ Each reveals different structural constraints  
✓ Different proof strategies become plausible in each  
✓ **Representation controls which obstructions are visible**, not just search cost
